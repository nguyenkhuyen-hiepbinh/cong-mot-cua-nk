Nhóm công việc và Loại tài khoản

Nhóm công việc là các mục lớn ở menu bên trái. Loại tài khoản là nhãn màu trên mỗi thẻ, cho biết đăng nhập bằng tài khoản nào.

    Loại tài khoản

      Có thay đổi chưa đăng lên GitHub

      Danh mục hiện có 0 hệ thống. Thay đổi đang nằm trên máy bạn — làm 4 bước dưới đây để cả trường cùng thấy.

      1. Bấm Sao chép nội dung mới ở dưới.
      2. Mở kho GitHub của cổng → bấm vào file dulieu.json → biểu tượng cây bút (Edit).
      3. Chọn hết nội dung cũ (Ctrl+A) rồi dán đè (Ctrl+V).
      4. Kéo xuống bấm Commit changes. Chờ khoảng 1 phút là trang web cập nhật.
      Mở kho GitHub
      SSO
      Phần lớn hệ thống dùng chung một tài khoản. Tài khoản Cơ sở dữ liệu Ngành — tên đăng nhập là số CCCD, mật khẩu do Nhà trường cấp — đăng nhập được cho mọi trang gắn nhãn Tài khoản CSDL ngành (SSO). Đăng nhập một lần rồi chuyển sang trang khác thường không phải nhập lại.
